# Phase 2 — Rust API, Leptos UI and existing sync operations

**Entry:** C02 validated snapshots and G0 decisions. **Exit:** An authenticated operator can inspect real status and operate existing router/LibreQoS sync controls. Profile, WAN and health actions wait for later phases. No visible write control reports success without a server result.
