# LQoSync4 planning workspace

This directory holds the LQoSync4 design. The surrounding checkout is the `lqosync4` branch based on LQoSync3. The new web application has not been implemented.

[Rust frontend options](docs/RUST_FRONTEND_OPTIONS.md) and [Rust backend options](docs/RUST_BACKEND_OPTIONS.md) record stack decisions. `graphify-out/` contains the knowledge graph.

Evidence labels: **Owner** = explicit direction; **Reference** = supplied video notes or screenshots; **LQoSync3** = read-only public source review; **Proposal** = design to validate before code.
