# Terms

| Term | Meaning |
|---|---|
| Subscriber | A customer connection identified from a confirmed source. |
| Upstream | An Internet connection usable by the MikroTik core. |
| Assignment | The selected upstream for a subscriber. |
| Manual pin | An operator-selected upstream for one subscriber. |
| Health | Measured upstream state; `unknown` is distinct from `up` and `down`. |
| Shadow mode | Compute and report a change without applying it. |
| App label | A possible app identity inferred from network evidence. |
