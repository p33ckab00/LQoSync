# Planning knowledge graph

`graph.json`, `graph.html`, and `GRAPH_REPORT.md` describe the LQoSync4 planning documents in this directory. The graph was built with Graphify from manual semantic extraction because no LLM extraction key was configured. It contains planning concepts and their documented relationships, not a graph of LQoSync4 source code.

Open `graph.html` locally or query `graph.json` with Graphify. Regenerate after the planning documents change; this snapshot does not update itself. The [LibreQoS v3 source map](../docs/LIBREQOS_V3_DATA_FLOW.md), [route/component contract](../docs/ROUTES_AND_COMPONENTS.md), and [visual/responsive map](../docs/UI_VISUAL_SYSTEM.md) are not yet included in this graph snapshot.
