Configuration workflow

  1. Add a router and explicitly test its connection.
  2. Select read credentials and supported write permissions.
  3. Add PPP, DHCP/IPoE, Hotspot, or WAN source policies.
  4. Configure queries, groups, identity, rates, and capacity.
  5. Preview the candidate and inspect validation on the canvas.
  6. Save valid configuration through the service.
  7. Load saved topology to display the saved configuration.

Preview stays optional. Valid accepted edits retain automatic apply.
